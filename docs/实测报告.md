# Arena + MCP 通路实测报告

> 目的：验证「不用 ShunCode、不反代，用 Arena 网页端 Agent 连 MCP 操作本机」这条路是否真的能跑通。
> 结论：**本机侧 100% 跑通并已实测通过**；Arena 侧待你在浏览器里贴一次链接确认。
> 全程使用**虚拟测试数据**，未触碰任何真实文件。ShunCode 未购买、未安装。

## 三、实测结果（原始输出）

从**公网地址**发起，验证全链路：

```
PUBLIC URL: https://<随机域名>.trycloudflare.com/mcp/<密钥>
  noToken   HTTP=401  "unauthorized"                      <- 鉴权生效
  init      HTTP=200  serverInfo={"name":"mcp-bridge-test","version":"1.0.0"}
  list      HTTP=200  tools=[ping, list_files, read_file]
  ping      HTTP=200  content="{\"magic\":\"MCP-BRIDGE-OK\",\"host\":\"cz\",\"platform\":\"win32\"}"
  read      HTTP=200  content="hello from the sandbox - this is DUMMY data..."
  escape    HTTP=200  content="path escapes sandbox"      <- 越界被拦
```

**关键意义**：`ping` 返回的 `host=cz` 是**本机主机名**，证明请求确实穿透公网隧道抵达了本机并执行。

## 四、两个必须知道的技术细节

### ① 首次安装需要重启终端

`winget` 装完 cloudflared 后，当前 shell 的 PATH 不会立即刷新。实际路径：

```
C:\Program Files (x86)\cloudflared\cloudflared.exe
```

### ② 鉴权必须用「路径密钥」或「Bearer 头」

这是**实测踩到的坑，也是你自研时必须解决的问题**：

- 如果只用 `Authorization: Bearer` 头，那么当网页 Agent **只能拿到一个 URL** 时（很多平台的自定义 Connector 不支持自定义请求头），它会收到 401，**连不上**；
- 因此本项目实现了**双模式**：密钥既可放在 `/mcp/<密钥>` 路径里，也可放在 Bearer 头里。

> **这一点正是 ShunCode 用「随机秘密路径」的原因**——不是它偷懒，而是**路径密钥是唯一能同时兼容所有网页平台的通用做法**。
> 但**更安全的做法是两者都支持**，然后在能从平台侧配置请求头时优先用头。

## 五、你的下一步：在 Arena 验证（约 5 分钟）

### 步骤 1 · 启动隧道（保持窗口开着）

```powershell
cd %USERPROFILE%\Desktop\dsh\mcp-bridge-test
node start-bridge.mjs
```

启动后终端会打印一个**可直接粘贴的 URL**（形如 `https://xxx.trycloudflare.com/mcp/<密钥>`）。

### 步骤 2 · 在 Arena 里测试

打开 <https://arena.ai/agent>，**新开一个对话**，把下面这段整个贴进去发送：

```
<把上一步打印的 URL 贴到这里>
请连接这个 MCP，调用 ping 工具，把返回的原文告诉我，然后列出你看到的全部工具。
```

### 步骤 3 · 判断结果

| 现象 | 含义 |
| --- | --- |
| 它调用 `ping` 并报出 `MCP-BRIDGE-OK` 和主机名 | ✅ **完全跑通**，整条路线成立 |
| 它说连不上 / 超时 / 无此能力 | ❌ Arena 未开放外部 MCP，此路不通 |
| 它说要装东西 / 要授权 | ⚠️ 部分支持，按其提示继续 |

> **注意**：必须**新开对话**再贴。旧对话不会记住这条 MCP。

## 六、安全说明（本测试项目的设计）

本项目刻意采用了比 ShunCode **更严格**的安全模型：

| 措施 | 说明 |
| --- | --- |
| **只读** | 只有 `ping` / `list_files` / `read_file`，**没有任何写入或执行能力** |
| **沙箱隔离** | 所有文件访问被限制在 `./sandbox` 内，越界直接拒绝 |
| **双模式鉴权** | 路径密钥 + Bearer 头，二者其一即可 |
| **无真实数据** | sandbox 内只有 `hello.txt` 和 `notes.md` 两个虚拟文件 |
| **一键停止** | `stop-bridge.cmd` 同时关闭服务与隧道 |

1. **先别急着换真数据**——保持只读工具跑几天，确认稳定；
2. **要接真实项目时**，把 sandbox 换成项目目录，但**保留路径白名单**；
