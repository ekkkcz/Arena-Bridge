# Arena Bridge 项目介绍文案

以下文案可用于仓库简介、社区发布、群聊分享和演示视频。

## 一句话定位

把 Arena 的网页 Agent 接到你的本机项目上。

## 仓库简介

连接 Arena Agent 与本机项目，支持文件读写、代码搜索和命令执行，并提供模型与推理档位识别、自动抽卡功能。

## 社区发布

最近做了一个开源工具 **Arena Bridge**，想把 Arena 里的 Agent 用到自己的本地项目上。

接通以后，可以直接在对话里让它读代码、改文件、补测试、跑命令，执行结果也会返回给 Agent，让它接着处理。

我还加了模型识别和自动「抽卡」：查看当前会话识别到的模型与推理档位，设置目标关键词，命中后停止，接着在这个对话里干活。

桌面版把连接和操作面板放在了一起，读、写、执行权限可以按需调整。适合个人项目、脚本调试和原型开发。

项目已开源，欢迎试用，也欢迎反馈连接、模型识别和实际使用中遇到的问题。

[GitHub · Arena Bridge](https://github.com/ekkkcz/Arena-Bridge)
